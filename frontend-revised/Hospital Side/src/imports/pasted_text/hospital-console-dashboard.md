Create a high-fidelity desktop web dashboard for "Docsahab — Hospital Console".

IMPORTANT:
Recreate the exact visual hierarchy, layout, spacing, card structure, proportions, colors, and content described below. Do not simplify the layout, do not invent new sections, and do not turn this into a generic hospital/admin dashboard.

The design should look like a premium real-time emergency coordination console: clean, calm, clinical, modern, highly readable, and optimized for emergency staff under pressure.

CANVAS:
- Desktop web application
- 1440px × 1024px style layout
- Full-width dashboard
- Fixed dark navy left sidebar approximately 205px wide
- Main content on a very light blue-white background
- Three main content areas:
  1. Emergency Queue
  2. Active Emergency
  3. Hospital Readiness / Actions

OVERALL VISUAL STYLE:
- Modern healthcare technology product
- Minimal but visually rich
- Very clean spacing
- White cards with subtle blue-gray borders
- Soft shadows
- Border radius around 12–16px
- Deep navy typography
- Dark navy sidebar
- Light blue-gray page background
- Red only for critical emergency information
- Orange for HIGH
- Amber/yellow for MODERATE
- Light blue for LOW
- Green for READY / AVAILABLE / CONNECTED
- Blue for neutral information and navigation
- Do not use excessive gradients
- Do not use glassmorphism
- Do not use unnecessary illustrations
- Do not use hospital building photographs
- Do not use ambulance photographs
- Do not make the interface flashy
- Keep it professional and realistic
